# Propulsa — Brand Guidelines

## Positioning

Luxury heritage lifestyle brand. Old-world/heritage luxury — fashion or fragrance house energy. Targets customers willing to pay premium prices. Not a discount-driven print-on-demand look.

## Logo

Ornate gold/bronze script "P" monogram with a refined small-caps serif wordmark.

## Color

- Ivory / cream (primary ground)
- Warm stone (secondary neutral)
- Deep espresso brown / near-black (primary dark)
- Warm gold / bronze (accent — used sparingly, never as a dominant color)

See `palette.json` for hex values — pulled directly from the live site's CSS tokens (`src/app/globals.css`), so print artwork matches the site exactly.

## Typography

Live site fonts (from `globals.css`): **Cormorant** (display/headings), **EB Garamond** (body), **Pinyon Script** (logo script mark only). No rounded or geometric "friendly" fonts. Any typography used directly on print artwork (e.g. a wordmark on packaging or a care label) should draw from this same set rather than introducing a new typeface.

## Visual language

- Generous whitespace
- Editorial photography
- Thin gold hairline details
- Slow, elegant motion
- No urgency tactics, no discount energy, no countdown/sale visual language

## Catalog approach

One cohesive brand aesthetic expressed across Contrado's catalog over time, organized around design **collections** that span multiple product types — not siloed by product niche. Sequence: towels → apparel → homeware → accessories, though a given collection's rollout order is determined by which product formats reuse the artwork most directly (see each collection's product roadmap).
