# Product Roadmap — Botanica Nocturne

Rollout order is based on which Contrado product formats reuse the towel artwork most directly, not strictly the brand's general towels → apparel → homeware → accessories sequence.

## Phase 1 — Towels (active, see `products/towels.md`)

Dense/all-over motif as a bordered treatment. 3 colorways, gold/gold-light accent finish variants. Full spec in `products/towels.md`.

## Phase 2 — Flat accessories

Same border-on-rectangle logic as the towel — reuses Phase 1 artwork with minimal rework.

- Table runners / tablecloths
- Tea towels
- Silk-effect scarf (uses the hairline border motif form primarily, dense field as an option)

## Phase 3 — Homeware

Dense/all-over motif at a different repeat scale than the towel border.

- Cushions
- Throws
- Wall art

## Phase 4 — Apparel

Needs the most new artwork — placement sizing and the single-sprig emblem form rather than the full dense pattern.

- Robes and loungewear first (large flat panels can take the dense pattern or a bold placement crop of it)
- Tops / outerwear using the single-sprig emblem (chest, cuff, hem placement) rather than an all-over print

## Notes

- Each phase needs its own `products/<phase>.md` spec file once the prior phase's artwork is finalized — don't spec Phase 2+ until Phase 1 towel artwork is locked, since later phases reuse it.
- Fig (secondary motif) is reserved for a second collection drop, not for filling out Phases 2–4 of Botanica Nocturne.
