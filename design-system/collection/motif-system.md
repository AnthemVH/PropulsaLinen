# Motif System — Botanica Nocturne

Every product in this collection is built from these 3 forms of the same olive-branch botanical. Do not design a new pattern per product — select the form that fits the product's surface.

## 1. All-over / dense field

The full engraved botanical repeat. Use where a large flat surface needs to carry the whole story.

- **Applies to:** towels (as a border treatment around the field), cushions, throws, tablecloths, wall art, homeware with large flat panels.
- **Rendering:** dense, engraved linework — think naturalist plate or apothecary label, not a flat repeat print.

## 2. Single-sprig emblem

One isolated branch or leaf cluster, pulled out of the dense pattern and used as a standalone mark.

- **Applies to:** apparel placement (chest, cuff, hem), smaller accessories where an all-over print would be too loud or too costly to execute well on garment-weight fabric.
- **Rendering:** same linework style as the dense field, just isolated — should look like a detail cropped from the larger pattern, not a redrawn simplification.

## 3. Hairline border / frame

The gold or ivory line-work that edges the dense pattern, usable on its own as a minimal trim.

- **Applies to:** scarf edges, napkin borders, bag piping, anywhere the full botanical doesn't fit but a collection "signature" is still wanted.
- **Rendering:** thin, consistent with the brand's gold hairline visual language (see `brand/guidelines.md`).

## Secondary motif (reserved)

Fig branch — held for a future second drop within Botanica Nocturne. Do not introduce it into Phase 1 (towels) or Phase 2 artwork without an updated collection brief.
